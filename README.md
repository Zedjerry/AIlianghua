> 这是为你量身定制的第一个 AI 量化项目：用机器学习（LightGBM）在沪深 300 成分股上做「横截面选股」，完整走一遍

## 🎯 这个项目在做什么（大白话）

1. **step1** 下载沪深 300 成分股 8 年的日线数据（2018 年至今，前复权）。
2. **step2** 给每只股票每天算一堆「特征」（过去 N 天涨跌幅、均线、波动率、成交量变化……）以及它在全市场的**排名**，再打上标签：**未来 5 天涨了多少**。
3. **step3** 让 LightGBM 模型从历史数据里学习「哪些特征组合 → 未来 5 天涨」的规律，用**时间上靠前的数据训练、靠后的数据验证/测试**（防止作弊），最后报告预测质量（IC、准确率）。
4. **step4** 在**模型从没见过**的最近一段数据上模拟真实交易：每 5 天从全市场挑预测涨幅最高的 20 只等权买入，算出净值曲线、年化收益、最大回撤、夏普比率，并和沪深 300 指数对比，最后画一张图。

> ⚠️ 重要：这是**学习项目**，不是荐股工具。回测好看 ≠ 实盘赚钱，切勿据此真金白银交易。

## 🚀 怎么运行（照着敲即可）

> 💡 换电脑/刚克隆仓库后，先跑一遍自检确认环境没问题：
> ```bash
> python selftest.py          # 快速自检；加 --full 会额外跑一遍回测
> ```

### 第 0 步：装依赖（只需要做一次）

在项目文件夹里打开终端（Windows 可在文件夹地址栏输入 `cmd` 回车），执行：

```bash
python -m pip install -r requirements.txt
```

### 第 1 步：一键跑通全流程

```bash
python run_all.py
```

> 第一次会花几分钟：下载 300 只股票的数据 + 训练模型。每步都有进度提示，耐心等。
> 如果想一步步来、边跑边学，就分别执行：
> `python step1_fetch_data.py` → `python step2_build_features.py` → `python step3_train_model.py` → `python step4_backtest.py`

### 第 2 步：看结果

- 终端会打印每一步的输出，最后回测会输出一张绩效表；
- 打开 `output/nav_curve.png` 看策略（蓝线）和沪深300指数（橙线）的净值对比；
- 打开 `output/backtest_report.txt` 看完整绩效指标。

## 🤖 每日交易信号（自动量化第一步）

**用法**：每天收盘后（或次日开盘前）运行一次：

```bash
python step5_generate_signals.py
```

它会自动完成：更新行情（数据 7 天内新鲜则秒级跳过）→ 算特征 → 用最新数据重新训练模型 → 预测 → 输出今日信号。

**输出**：
- 终端打印「预测未来 5 日涨幅 Top 20」清单（代码/名称/收盘价/预测涨幅）
- `output/signals_today.csv` 完整信号表
- `output/latest_model.txt` 每日自动更新的模型

**怎么用它验证信号质量（重要）**：
1. 记录今日 Top 20 清单；
2. 5 个交易日后回看这 20 只股票的实际平均涨幅，和「沪深300同期涨幅」对比；
3. 连续记录 5~10 次，如果胜率明显高于 50%、平均跑赢指数，才说明信号有真实预测力；
4. 这之后才考虑对接券商接口（QMT）自动下单。

⚠️ **step5 只生成信号、不自动下单**。自动下单属于阶段3（对接券商 QMT/PTrade 接口），需要单独开通权限并做好风控。

## 🛡️ 风控与实盘模块（阶段3/4）

- **调仓决策**（`rebalance.py`）：卖出不在名单的、等权买入名单内的，纯函数无副作用——模拟盘和实盘共用，保证"决策不会走样"。
- **风控规则**（`risk_manager.py`）：单日亏损 >3% 熔断买入、距高点回撤 >15% 清仓、单票仓位 ≤10%。可独立运行自测：`python risk_manager.py`。
- **QMT 下单**（`trade_qmt.py`）：预览模式用模拟盘账户演示完整下单流程（现在就能跑）；开通 QMT 权限后加 `--live` 参数执行真实下单。

**实盘前 checklist（缺一不可）**：
1. 模拟盘向前验证 2~3 个月，胜率 >60% 且平均超额 >0；
2. QMT 权限开通 + 小额试单通过；
3. 跑 `python trade_qmt.py` 预览，人工核对订单；
4. 实盘首月用小资金 + 每天人工盯盘，确认无误再逐步放大。

**告警通知**（`notify.py`）：每日流水线失败、风控熔断/清仓触发时会自动记录到 `output\alerts.log` 并在控制台提示。想收到邮件/桌面气泡，在 `notify.py` 顶部配置即可；可随时运行 `python notify.py` 自测。

**可视化看板**（`dashboard.py`）：把模拟盘净值、今日信号、持仓、信号评估、告警汇总成一个网页（`output\dashboard.html`）。运行 `python dashboard.py` 生成并打开浏览器，`run_daily` 每次也会自动更新看板。

**可视化 UI**（`webui.py`）：**推荐日常使用**——本地网页服务，浏览器操作：
```bash
python webui.py            # 启动后打开 http://127.0.0.1:8000
```
- 5 个页面：概览（净值曲线/指标卡片）/ 信号 / 模拟盘 / 评估 / 告警
- 一键按钮：运行每日流程、重置模拟盘、刷新图表
- 每 20 秒自动刷新，后台任务状态实时显示

**参数敏感性实验**（`experiment.py`）：一键扫描「持仓数 × 换仓频率」6 种组合，看收益/回撤对参数敏不敏感（过拟合预警）。实测结论：当前策略对参数**高度敏感**（最好与最差年化差 55%），实盘前务必谨慎——这也是学习量化的核心一课。

**滚动样本外检验**（`walkforward.py`）：把 2019 年至今切成 14 个半年期，每期只用之前的数据训练、在没见过的时期评估。实测结论：**14/14 期 IC 为正（平均 +0.099），平均超额 +1.06%/5日**——策略跨牛熊环境较稳健。这是目前最有力的策略证据，但仍需向前验证 + 实盘检验。

## 🧪 预期结果（本项目实测参考）

- `step3` 打印：测试集 IC 约 **0.09**、方向准确率约 50%（IC 在 0.02~0.08 都是正常的，别期待 70%+，那是过拟合信号）；

> 这些数字只说明「你的代码跑通了、结果合理」，不代表策略能稳定赚钱。机器学习模型的规律会随时间衰减，实盘前必须持续做样本外验证。

**数据源说明**：本项目用 **akshare**（行情走新浪财经接口，成分股列表带多数据源自动切换），脚本内置自动重试与限速，接口偶尔断连会自动重试，无需担心。

## ❗ 常见坑（提前给你打预防针）

1. **回测收益 ≠ 实盘收益**：我们已计入 0.2% 换仓成本，但实盘还有滑点、涨跌停买不进等问题。
2. **数据一定要前复权**：step1 已处理（qfq）。
3. **训练/测试必须按时间切**：step3 已处理，千万别改成随机打乱。
4. **不要反复调参直到回测好看**：那是自欺欺人。
