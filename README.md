# 📈 AI 多因子选股项目（小白从零版）

> 这是为你量身定制的第一个 AI 量化项目：用机器学习（LightGBM）在沪深 300 成分股上做「横截面选股」，完整走一遍
> **数据 → 特征 → 模型 → 回测** 的量化全流程。
> 全部代码已帮你写好、注释详细，你只需要按顺序运行 4 个脚本，并在过程中理解每一步在干什么。

---

## 🎯 这个项目在做什么（大白话）

1. **step1** 下载沪深 300 成分股 8 年的日线数据（2018 年至今，前复权）。
2. **step2** 给每只股票每天算一堆「特征」（过去 N 天涨跌幅、均线、波动率、成交量变化……）以及它在全市场的**排名**，再打上标签：**未来 5 天涨了多少**。
3. **step3** 让 LightGBM 模型从历史数据里学习「哪些特征组合 → 未来 5 天涨」的规律，用**时间上靠前的数据训练、靠后的数据验证/测试**（防止作弊），最后报告预测质量（IC、准确率）。
4. **step4** 在**模型从没见过**的最近一段数据上模拟真实交易：每 5 天从全市场挑预测涨幅最高的 20 只等权买入，算出净值曲线、年化收益、最大回撤、夏普比率，并和沪深 300 指数对比，最后画一张图。

> ⚠️ 重要：这是**学习项目**，不是荐股工具。回测好看 ≠ 实盘赚钱，切勿据此真金白银交易。

## 🚀 怎么运行（照着敲即可）

### 第 0 步：装依赖（只需要做一次）

在项目文件夹里打开终端（Windows 可在文件夹地址栏输入 `cmd` 回车），执行：

```bash
python -m pip install -r requirements.txt
```

### 第 1 步：一键跑通全流程

```bash
python run_all.py
```

> 第一次会花几分钟：下载 300 只股票的数据 + 训练模型。每步都有进度提示，耐心等。
> 如果想一步步来、边跑边学，就分别执行：
> `python step1_fetch_data.py` → `python step2_build_features.py` → `python step3_train_model.py` → `python step4_backtest.py`

### 第 2 步：看结果

- 终端会打印每一步的输出，最后回测会输出一张绩效表；
- 打开 `output/nav_curve.png` 看策略（蓝线）和沪深300指数（橙线）的净值对比；
- 打开 `output/backtest_report.txt` 看完整绩效指标。

## 🧭 学习路线（每步对应一个脚本）

| 阶段 | 脚本 | 你该学会的东西 | 预计投入 |
|---|---|---|---|
| 0. 基础 | — | Python 基础 + pandas 读表（建议先跑通再看） | 1 周 |
| 1. 数据 | step1 | 什么是前复权、K线、为什么用「成分股」 | 1–2 天 |

## 📖 每个脚本的阅读顺序建议

- 先只看 `step1` 的 `main()` 和注释，明白「下载了什么、存到了哪」；
- 跑完再打开 `step2`，重点看 `build_features()` 和「标签」部分；
- `step3` 重点看「训练/验证/测试切分」那段代码——这是防作弊的关键；
- `step4` 重点看 `rebalance` 和成本计算。

**遇到报错怎么办**：先看终端最后几行；网络类报错（接口断连/超时）脚本会自动重试，多等一会儿即可；其他报错把信息发给我，我来修。

## 🧪 预期结果（本项目实测参考）

- `step3` 打印：测试集 IC 约 **0.09**、方向准确率约 50%（IC 在 0.02~0.08 都是正常的，别期待 70%+，那是过拟合信号）；
- `step4` 打印：策略年化收益约 **69%**、夏普约 **1.7**、最大回撤约 -24%，同期沪深300约 +18%——注意这是测试期（约 1 年半）的表现，**不同时间段、不同参数结果都会变**；
- 图里蓝线（策略）明显跑赢橙线（沪深300）。

> 这些数字只说明「你的代码跑通了、结果合理」，不代表策略能稳定赚钱。机器学习模型的规律会随时间衰减，实盘前必须持续做样本外验证。

**数据源说明**：本项目用 **akshare**（成分股列表走中证指数官网，行情走新浪财经接口），脚本内置自动重试与限速，接口偶尔断连会自动重试，无需担心。

## ❗ 常见坑（提前给你打预防针）

1. **回测收益 ≠ 实盘收益**：我们已计入 0.2% 换仓成本，但实盘还有滑点、涨跌停买不进等问题。
2. **数据一定要前复权**：step1 已处理（qfq）。
3. **训练/测试必须按时间切**：step3 已处理，千万别改成随机打乱。
4. **不要反复调参直到回测好看**：那是自欺欺人。
