# AI 量化系统 使用手册

> 面向完全小白的完整使用说明。先读这份，再动手。

---

## 1. 这套系统是什么（一段话）

一套**全自动的 A 股量化选股系统**：每天收盘后自动下载行情 → 用机器学习模型（LightGBM）
预测未来 5 日涨幅 → 选出 Top20 股票 → 存档并评估信号质量 → 在模拟盘里自动"买卖"
验证 → 生成网页看板让你一目了然 → 出问题自动告警。将来开通券商 QMT 权限后，
还能把模拟盘的"假买卖"换成"真下单"，实现自动量化交易。

## 2. 系统架构

```
每天 16:40（计划任务自动触发，或手动 python run_daily.py）
┌──────────────────────────────────────────────────────────┐
│ step5 生成今日信号（更新行情→算特征→重训模型→Top20清单）      │
│ step6 存档信号 + 5日后自动核算实际表现（胜率/超额）            │
│ step7 模拟盘自动执行（调仓/成本/风控）                       │
│ dashboard 生成网页看板                                      │
└──────────────────────────────────────────────────────────┘
         │ 任一步失败
         ▼
   notify 告警（控制台/文件/邮件/气泡）
         │ 风控触发（熔断/清仓）
         ▼
   risk_manager 决策 + alerts.log 留痕
```

实盘层（QMT 权限开通后启用）: `trade_qmt.py --live`，调仓决策与模拟盘**完全同一套代码**（rebalance.py），只换执行通道。

## 3. 文件地图（每个文件是干什么的）

| 文件 | 作用 | 你何时需要碰它 |
|---|---|---|
| `run_all.py` | 学习用：跑通 1→4 步 | 刚入门时 |
| `run_daily.py` | **日常主力**：5→6→7→看板 一键跑 | 每天（或交给计划任务） |
| `step1~4` | 数据/特征/模型/回测（学习主线） | 想理解原理时 |
| `step5` | 生成今日信号 | 由 run_daily 调用 |
| `step6` | 信号存档与质量评估 | 由 run_daily 调用 |
| `step7` | 模拟盘执行 | 由 run_daily 调用 |
| `rebalance.py` | 调仓决策（模拟盘/实盘共用） | 想调交易逻辑时 |
| `risk_manager.py` | 风控规则 | 想改风控参数时 |
| `notify.py` | 告警（顶部可配邮件） | 想收邮件通知时 |
| `dashboard.py` | 网页看板 | 想看结果时 |
| `connection.py` | 断线重连 | 实盘连接用 |
| `selftest.py` | 一键自检 | 换电脑/出问题时 |
| `go_live_check.py` | 实盘上线检查 | 准备实盘前 |
| `setup_schedule.bat` | 注册每日自动任务 | 第一次部署时 |
| `docs/QMT接入指南.md` | QMT 开通与接入 | 准备实盘时 |

## 4. 日常操作清单

**每天（全自动后基本不用管）**：
- 想确认跑没跑成功：看 `output\daily_logs\` 最新日志，或 `output\alerts.log`
- 想看结果：`python dashboard.py`（或直接打开 `output\dashboard.html`）

**每周**：
- 打开看板看：模拟盘净值曲线、信号胜率有没有变化

**每月**：
- 跑一次 `python selftest.py --full` 确认系统健康
- 整理 `output\signal_evaluation.csv`，看信号是否持续跑赢指数

## 5. 常见问题（FAQ）

**Q: 报错"接口断连/SSL"怎么办？**
A: 数据源偶尔抽风，脚本会自动重试。多次失败就等几分钟重跑 `python run_daily.py`。

**Q: 数据一直"未更新"？**
A: 删掉 `data\stock_daily.csv` 再跑 `python run_daily.py` 会强制重新下载。

**Q: 模拟盘持仓为什么不是 20 只？**
A: 高价股一手（100 股）买不起就自动跳过（如茅台 15 万/手），这是真实约束，属正常。

**Q: 想重置模拟盘？**
A: 删除 `output\paper_account.json` 再跑 step7。

**Q: 信号胜率多少才算合格？**
A: 向前验证胜率 >60% 且平均超额 >0。回填的"历史战绩"只算演示，不算数。

**Q: 什么时候能实盘？**
A: 三步：① 模拟盘向前验证 2~3 个月达标；② QMT 权限开通；③ 跑 `go_live_check.py` 得到 GO，然后小额试单。

## 6. 上线流程（从模拟盘到实盘）

```
模拟盘验证达标（胜率>60%、超额>0，2~3个月）
   → 开通 QMT（docs/QMT接入指南.md）
   → python go_live_check.py  看是否 GO
   → python trade_qmt.py      预览订单（不真下单）
   → python trade_qmt.py --live ...   小额试单（≤1万元）
   → 每天人工盯盘 1 个月，确认无误
   → 逐步放大资金
```

## 7. 重要提醒（请务必牢记）

1. 回测/模拟盘的收益**不代表实盘收益**，实盘会打折扣；
2. 模型规律会随时间衰减，要持续跟踪信号评估；
3. 实盘永远从最小资金开始，风控规则（止损/清仓）务必保留；
4. 本系统仅供学习研究，**不构成投资建议**。
